# Разработка SnippetDeck

В репозитории два приложения с общими пользовательскими форматами резервных копий и синхронизации. Android-код в `app/` использует Kotlin, Room, Compose и AccessibilityService. Desktop-код в `desktop/` использует Rust, Tauri и статический веб-редактор. Устанавливайте инструменты для нужной платформы: для изменения desktop Android SDK не требуется.

## Android

Установите JDK 17 и Android SDK Platform 37.0 (`sdkmanager --channel=3 'platforms;android-37.0'`). Целевая версия приложения остаётся Android 36. Укажите путь к SDK в игнорируемом `local.properties` (пример — `local.properties.example`) или откройте проект в Android Studio. Для ручной проверки нужен Android 13+ или эмулятор.

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug --no-daemon --max-workers=2
```

Отладочный APK появится в `app/build/outputs/apk/debug/` и имеет отдельный идентификатор с суффиксом `.debug`: его можно установить рядом с официальной версией. Изменения службы специальных возможностей проверяйте вводом хотя бы в двух редакторах — unit-тесты не отражают поведение всех полей.

С подключённым устройством или эмулятором выполните `./gradlew connectedDebugAndroidTest --no-daemon --max-workers=2`: это проверяет интерфейс и целостность Room, включая миграцию v1→v2. При ограниченных ресурсах сначала соберите приложение, затем запускайте эмулятор.

## Windows, macOS и Linux

Установите Rust и [зависимости Tauri](https://v2.tauri.app/start/prerequisites/) для своей ОС. В Debian/Ubuntu также нужен `libxdo-dev`. В `desktop/ui/` лежит статический интерфейс; устанавливать пакеты frontend не нужно.

```bash
cd desktop/src-tauri
cargo test --locked
cargo build --locked
```

Исполняемый файл появится в `desktop/src-tauri/target/debug/`, если вы не задали `CARGO_TARGET_DIR`. Для входа в Google Drive в локальной сборке нужна переменная сборки `SNIPPETDECK_DESKTOP_OAUTH_CLIENT_SECRET`; остальные функции работают без неё. Не помещайте учётные данные в исходники и логи. GitHub Actions собирает пакеты на runner’ах соответствующих ОС; порядок официального выпуска описан в [Эксплуатации](OPERATIONS.md).

Windows CI также открывает Microsoft Edge и проверяет настоящий обработчик клавиатуры и вставку в textarea и contenteditable. Проверка охватывает русские и английские псевдонимы, текст вокруг курсора, повторные вставки, Unicode, Backspace и сохранение буфера обмена. Для локального запуска в интерактивном сеансе Windows с установленным Edge выполните `cargo test --locked windows_browser_replacements -- --ignored --nocapture --test-threads=1`. Проверка ненадолго забирает фокус и использует временный профиль браузера.

## Что сохранять при изменениях

Находите триггер перед курсором, сохраняйте текст после него и никогда не отправляйте поле ввода. Основные триггеры и псевдонимы должны оставаться уникальными без учёта регистра. Многострочную подстановку на компьютере выполняйте вставкой, без имитации Enter. Сохраняйте установленные Android-идентификаторы, миграции Room, подпись, чтение резервных копий и формат `snippetdeck-sync`: существующие установки должны прочитать свои данные после обновления.

Выбирайте минимальную проверку, доказывающую изменение. Форматы копий и база данных требуют проверки кругового импорта или миграции; интерфейс — снимка или ручной проверки. Сниппеты остаются локальными, пока пользователь сам не подключит Google Drive. Не добавляйте сервер, токены в установщик или фоновый опрос. Стабильный релиз должен содержать официальный подписанный Android APK и все четыре desktop-установщика.

В pull request опишите заметный пользователю результат и проверки. Узкие изменения легче проверять, чем случайную уборку попутно. Вклад распространяется по [лицензии MIT](../../LICENSE); указание авторов Expander сохраняется.

Корневой `LICENSE` — канонический текст лицензии. Android копирует его в генерируемые assets; desktop включает как ресурс и указывает MIT в метаданных Cargo. Сохраняйте текст лицензии и в распространяемых пакетах, и в исходниках.

## Визуальные материалы

Значок сочетает чернильный скруглённый квадрат (`#282832`), светлые скобки (`#F6F3ED`) и лавандовый плейсхолдер (`#C8C8EE`). Исходные векторы — `design/app_icons/source/icon.svg` и `icon-foreground.svg`. Остальная часть каталога — готовый набор ресурсов Android для повторного использования; копии в `app/src/main/res/` входят в приложение. При повторном экспорте векторов обновляйте оба набора.

Размеры значков для mdpi–xxxhdpi: 48, 72, 96, 144 и 192 px; адаптивных передних слоёв — 108, 162, 216, 324 и 432 px. Содержимое переднего слоя держите в безопасной зоне 66/108. Растр для Play Store — 512 px. Desktop использует `desktop/src-tauri/icons/`, favicon сайта — `docs/images/`. Снимки в `docs/images/` должны показывать демонстрационные данные и актуальное поведение.

## Документация и языки

У документации пять категорий: повседневное использование в `GUIDE.md`, разработка здесь, границы кода в `ARCHITECTURE.md`, выпуск и сопровождение в `OPERATIONS.md`, обработка данных в `PRIVACY.md`. README представляет продукт и ведёт к этим категориям. Держите одно объяснение каждой темы, а с остальных страниц ссылайтесь на него.

Английские тексты сохраняют обычные пути в корне и `docs/`. Каждый другой язык повторяет те же имена файлов в `docs/<код-языка>/`, категории, порядок разделов и примеры. Украинский добавляется в `docs/uk/`, немецкий — в `docs/de/`, остальные — в собственный каталог; генератор и изменения приложения не нужны. Добавьте язык в таблицу README и навигацию страниц всех существующих языков. Сайт следует тому же правилу: `docs/<код-языка>/index.html` и `privacy.html`; английские версии находятся прямо в `docs/`.

Обновляйте затронутые переводы вместе с поведением, командами и конфигурацией. Передавайте смысл естественным языком, не копируя структуру предложений. При изменении потоков данных обновляйте и Markdown-политики, и публичные HTML-страницы. Интерфейс приложения пока английский: в переводах документации сохраняйте реальные названия элементов управления.
