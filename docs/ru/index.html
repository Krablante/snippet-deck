Быстрая подстановка

Введите триггер, например !review, и нажмите пробел. Псевдонимы и подстановки даты экономят повторный ввод.

Данные у вас

Библиотека хранится на устройстве. Резервная копия в JSON или компактном тексте пригодится для переноса.

Синхронизация по желанию

Подключите Google Drive для обмена между устройствами. Офлайн-правки сохранятся, а конфликтующие изменения потребуют вашего выбора.

Одна библиотека на разных устройствах

Подписанный Android APK и установщики для Windows, macOS и Linux находятся в одном релизе GitHub. Нужен Android 13 или новее. В Linux подстановка работает в X11; в Wayland остаётся редактор библиотеки.

Ваш Google Drive — ваш выбор

Синхронизация необязательна. После вашего согласия SnippetDeck записывает сниппеты в закрытую для других приложений папку данных Drive. Google может читать их: сквозного шифрования нет. У SnippetDeck нет своего сервера аккаунтов и аналитики. Перед подключением прочтите политику конфиденциальности.

SnippetDeck распространяется с открытым исходным кодом по лицензии MIT.
